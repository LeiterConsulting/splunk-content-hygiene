# Support

This beta is intended for evaluation on a non-production Splunk Enterprise
search head.

For reproducible bugs or feature requests, open a
[GitHub Issue](https://github.com/LeiterConsulting/splunk-content-hygiene/issues).
Include the app version, Splunk version, scan mode, affected page, browser, and
sanitized error text. Do not include credentials, session values, customer
content, exported inventories, or `.env` files.

Use the private process in [SECURITY.md](SECURITY.md) for suspected
vulnerabilities.

Splunk Content Hygiene is not affiliated with or endorsed by Splunk Inc. Splunk
is a trademark of Splunk Inc.
